# XXA IP Tool 

XXA IP Tool, IP adresleri hakkında temel ve gelişmiş ağ bilgilerini gösteren basit bir Python aracıdır.

##  Özellikler

- IP adresi bilgisi sorgulama
- Ülke, şehir, bölge tespiti
- ISP ve ASN bilgisi
- Koordinat (enlem / boylam)
- Reverse DNS çözümleme
- Kendi IP adresini otomatik bulma
- JSON ham veri çıktısı
- Çoklu API desteği

---

##  Gereksinimler

- Python 3.8+
- requests kütüphanesi
- Linux / Windows / Termux uyumlu
